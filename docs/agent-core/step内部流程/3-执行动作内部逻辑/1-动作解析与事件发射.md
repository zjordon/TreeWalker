# 1-动作解析与事件发射

> 源码位置: `src/tree_walker/agent/step.py` 第 503-520 行

## 📋 方法作用

在执行动作前进行前置检查（stopped/paused），解析 LLM 输出中的动作名称和参数，并通过 EventBus 发射 ToolCallEvent。

## 🔄 主要逻辑流程

```
_execute_actions() (L503-520)
  │
  ├── 前置检查                                   (L503-504)
  │   └── if stopped or paused → return [ActionResult(error="Agent stopped or paused")]
  │
  ├── 解析动作                                   (L506-508)
  │   ├── action = model_output.get("action", {})
  │   ├── action_name = action.get("name", "done")
  │   └── action_params = action.get("params", {})
  │
  └── 发射 ToolCallEvent                        (L510-520)
        └── {step, session_id, model_call_id, tool_call_id, action_name, params}
```

## 🔍 详细步骤说明

### 1. stopped/paused 检查 (L503-504)

在执行任何动作之前检查 Agent 是否已被用户停止或暂停。如果是，返回错误结果而不执行任何浏览器操作。

### 2. 动作解析 (L506-508)

```python
action = model_output.get("action", {})
action_name = action.get("name", "done")       # 默认 done
action_params = action.get("params", {})        # 默认空参数
```

使用 `.get()` 带默认值，即使 LLM 输出格式异常也能安全降级。

### 3. ToolCallEvent (L510-520)

```python
if self._obs_bus:
    tool_call_id = uuid.uuid4().hex[:8]
    self._obs_bus.emit(ToolCallEvent(
        step=self.state.n_steps,
        session_id=self._obs_session_id,
        model_call_id=getattr(self, "_current_model_call_id", ""),
        tool_call_id=tool_call_id,
        action_name=action_name,
        params=action_params,
    ))
```

记录 model_call_id → tool_call_id 的关联，用于可观测性追踪"哪个 LLM 决策导致了哪个动作"。

## 🎯 设计亮点

1. **安全默认值** — 动作名默认 "done"，参数默认空字典，防止 KeyError
2. **关联追踪** — tool_call_id 关联到 model_call_id，实现完整的决策链追踪
