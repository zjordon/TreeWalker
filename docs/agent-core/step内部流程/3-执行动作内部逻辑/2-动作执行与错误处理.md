# 2-动作执行与错误处理

> 源码位置: `src/tree_walker/agent/step.py` 第 522-556 行

## 📋 方法作用

执行动作并处理各类异常。通过超时保护防止动作阻塞，连接错误向上传播触发重连，其他错误捕获为 ActionResult。

## 🔄 主要逻辑流程

```
_execute_actions() (L522-556)
  │
  ├── pre_action_url = browser_state.url              (L522)
  │
  ├── try:
  │     result = await asyncio.wait_for(               (L525-528)
  │         tools.execute(action_name, params, browser, browser_state),
  │         timeout=action_timeout,                     # 默认 30s
  │     )
  │

        ├── post_url = await browser.get_current_url()

```

## 🔍 详细步骤说明

### 1. 动作超时保护 (L525-528)

```python
result = await asyncio.wait_for(
    self.tools.execute(action_name, action_params, self.browser, browser_state),
    timeout=self.action_timeout,    # 默认 30 秒
)
```

每个动作独立计时，超时后返回错误 ActionResult 而非阻塞主循环。

### 2. 异常三分支 (L529-536)

```
异常类型判断:
├── asyncio.TimeoutError → ActionResult(error="Action timed out...")
├── _is_connection_error(e) → raise (向上传播到 _handle_step_error)
│   └── WebSocket 断开、浏览器关闭等 → 触发重连循环
└── 其他 Exception → ActionResult(error="{Type}: {message}")
    └── JavaScript 错误、元素未找到等 → 记录但不中断
```

**连接错误判断**（step.py L716-732）：
```python
_CONNECTION_ERROR_PATTERNS = (
    "websocket connection closed",
    "connection closed",
    "connection reset",
    "browser has been closed",
    ...
)
```

### 3. ToolResultEvent (L538-546)

```python
if self._obs_bus and tool_call_id:
    self._obs_bus.emit(ToolResultEvent(
        step=self.state.n_steps,
        tool_call_id=tool_call_id,
        success=result.success,
        error=result.error,
        duration_seconds=time.time() - tool_start,
    ))
```

记录动作执行结果和耗时，用于可观测性追踪。

### 4. URL 变化检测 (L548-554)

```python
if not result.error and action_name not in _NO_URL_CHECK_ACTIONS:
    post_url = await self.browser.get_current_url()
    if post_url and post_url != pre_action_url:
        logger.debug("Page changed after '%s': %s -> %s", ...)
```

部分动作（click、input_text、scroll 等）不触发 URL 变化检测，避免无意义的 CDP 调用。

豁免列表：
```python
_NO_URL_CHECK_ACTIONS = frozenset({
    "click", "input_text", "scroll", "send_keys", "wait",
    "extract", "find_elements", "find_text", "search_page",
    "dropdown_options", "select_dropdown", "screenshot",
    "save_as_pdf", "upload_file", "read_file", "write_file", "replace_file",
})
```

## 🎯 设计亮点

1. **异常分类传播** — 连接错误向上传播触发重连，其他错误捕获为 ActionResult
2. **独立超时** — `action_timeout` 与 `llm_timeout` 分离，互不影响
3. **URL 检测豁免** — 不变页面的动作跳过 URL 检查，减少 CDP 调用
