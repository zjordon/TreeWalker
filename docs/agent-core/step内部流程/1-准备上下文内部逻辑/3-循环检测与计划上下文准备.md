# 3-循环检测与计划上下文准备

> 源码位置: `src/tree_walker/agent/step.py` 第 136-153 行

## 📋 方法作用

执行两项准备工作：(1) 将当前页面 URL 记录到循环检测器；(2) 如果启用了计划系统，渲染当前计划描述并生成规划引导 nudge。

## 🔄 主要逻辑流程

```
_prepare_context() (L136-153)
  │
  ├── 循环检测记录                            (L136)
  │   └── loop_detector.record_page(browser_state.url)
  │
  └── 计划上下文（可选，if enable_planning）   (L139-153)
        │
        ├── plan_description = plan_manager.render_plan_description(state.plan)
        │     └── 渲染计划文本: "[x] 0: 步骤一\n[>] 1: 步骤二\n[ ] 2: 步骤三"
        │
        ├── planning_nudge = plan_manager.build_replan_nudge(...)
        │     └── if consecutive_failures >= threshold → "Consider revising the plan..."
        │
        └── planning_nudge ||= plan_manager.build_exploration_nudge(...)
              └── if n_steps >= threshold and no plan → "Consider breaking down the task..."
```

## 🔍 详细步骤说明

### 1. 循环检测记录 (step.py L136)

```python
self.loop_detector.record_page(browser_state.url)
```

将当前 URL 追加到 `recent_urls` 双端队列（maxlen=15）。用于后续检测是否在不同页面间来回跳转。

### 2. 计划描述渲染 (step.py L142-144)

`PlanManager.render_plan_description()` 将当前计划渲染为人类可读文本：

```
[x] 0: 打开登录页面
[>] 1: 输入用户名和密码
[ ] 2: 点击登录按钮
[ ] 3: 验证登录成功
```

状态标记：`[x]` 完成、`[>]` 当前、`[ ]` 待办、`[-]` 跳过。

### 3. 规划引导生成 (step.py L145-153)

两条互斥的 nudge 路径：

**重新规划 nudge** — 连续失败超过阈值时触发：
```python
planning_nudge = self.plan_manager.build_replan_nudge(
    self.state.consecutive_failures,  # 当前连续失败数
    self._replan_failure_threshold,   # 阈值（默认 3）
    self.state.plan,                  # 当前计划
)
```

**探索引导 nudge** — 无计划探索超过阈值步数时触发：
```python
planning_nudge ||= self.plan_manager.build_exploration_nudge(
    self.state.n_steps,               # 当前步数
    self._exploration_threshold,      # 阈值（默认 5）
    self.state.plan,                  # None 表示无计划
)
```

nudge 会在后续 `build_state_message()` 中以 `[Planning Suggestion]` 段注入 LLM 上下文。

## 🎯 设计亮点

1. **互斥 nudge** — replan 和 exploration 不会同时触发，优先 replan
2. **软引导** — 不强制 LLM 修改计划，只是建议
3. **可配置阈值** — `exploration_threshold` 和 `replan_failure_threshold` 均可通过 settings 调整

## 📊 返回值结构

```
plan_description: str | None    — 计划渲染文本，无计划时为 None
planning_nudge: str | None      — 规划引导文本，无触发条件时为 None
```
