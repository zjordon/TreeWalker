# 2-日志记录与动作模型更新

> 源码位置: `src/tree_walker/agent/step.py` 第 130-207 行

## 📋 方法作用

两步操作：(1) 记录当前步骤的上下文信息到日志；(2) 根据当前页面 URL 动态更新动作模型和 tool schema，实现页面级动作过滤。

### 2. _update_action_models_for_page (step.py L197-207)

**关键设计**：每一步都根据当前 URL 重新生成 tool schema 和系统提示。

```python
def _update_action_models_for_page(self, page_url):
    self._tool_schema = self.tools.registry.get_tool_schema(
        page_url=page_url,             # 触发页面过滤
        enable_planning=self._enable_planning,
        output_mode=self._output_mode,
    )
    self._system_prompt = build_system_prompt(
        action_descriptions=self.tools.registry.get_action_descriptions_text(
            page_url=page_url,          # 过滤后的动作描述
        ),
        task=self._safe_task,
        enable_decision_attribution=...,
    )
```

**页面过滤逻辑**（registry.py L30-36）：
```python
def _action_available(self, name, page_url):
    if page_url is None: return True
    action = self.actions[name]
    if action.page_patterns is None: return True   # 无过滤规则
    return any(fnmatch(page_url, p) for p in action.page_patterns)
```

通过 `fnmatch` glob 模式匹配 URL，例如 `{"upload_file": ["*.bilibili.com/*"]}` 只在 B 站页面显示上传功能。

## 🎯 设计亮点

1. **动态 schema** — 每步根据 URL 重新生成，LLM 只看到当前页面可用的动作
2. **页面级过滤** — 通过 glob 模式按 URL 启用/禁用动作，减少 LLM 困惑
3. **系统提示同步更新** — schema 和描述文本同时更新，保持一致

## 📊 返回值结构

无显式返回值。更新 `self._tool_schema` 和 `self._system_prompt` 两个实例属性。
