# 4-构建状态消息

> 源码位置: `src/tree_walker/agent/step.py` 第 156-182 行
> 消息构建: `src/tree_walker/prompts/system_prompt.py` 第 65-139 行

## 📋 方法作用

将浏览器状态、前序上下文、循环检测 nudge、计划描述、下载通知等所有信息组装成一条完整的 user 消息，追加到 `self.messages` 列表中。

## 🔄 主要逻辑流程

```
_prepare_context() (L156-182)
  │
  ├── nudge = loop_detector.get_nudge_message()     (L156)
  │     └── 检查最近动作重复次数 → 分级 WARNING/CRITICAL
  │
  ├── 下载通知（可选）                                (L159-167)
  │   ├── browser.consume_completed_downloads()
  │   └── download_notice = "New files available: ..."
  │
  ├── state_msg = build_state_message(...)           (L169-181)
  │     ├── [Task] 任务描述
  │     ├── [Previous Goal/Evaluation/Memory] 前序上下文
  │     ├── [Previous Action Results] 上步结果
  │     ├── [Current Plan] 计划描述（可选）
  │     ├── [Current URL] + [Page Title]
  │     ├── [Open Tabs] 标签页列表
  │     ├── [Page DOM] DOM 树文本
  │     ├── [Downloads] 下载通知（可选）
  │     ├── [System Notice] 循环检测 nudge（可选）
  │     └── [Planning Suggestion] 规划引导（可选）
  │
  └── messages.append({"role": "user", "content": state_msg}) (L182)
```

## 🔍 详细步骤说明

### 1. 循环检测 nudge 获取 (step.py L156)

```python
nudge = self.loop_detector.get_nudge_message()
```

检查 `recent_actions` 中的重复频率：
- 重复 < 5 次 → None
- 5-7 次 → WARNING（"Consider whether you are making progress"）
- 8-11 次 → 强 WARNING（"You are likely stuck in a loop"）
- 12+ 次 → CRITICAL（"You must immediately try a completely different approach"）

### 2. 下载通知 (step.py L159-167)

```python
if self._track_downloads:
    new_downloads = self.browser.consume_completed_downloads()
    if new_downloads:
        for d in new_downloads:
            self.state.downloaded_files.append(DownloadInfo(**d))
        download_notice = f"New files available: {file_list}"
```

消费已完成的下载队列，将文件信息存入 `state.downloaded_files`，生成通知文本。

### 3. build_state_message() (system_prompt.py L65-139)

将所有信息段组装为一条 user 消息，各段结构：

```
[Task] 搜索 Python 教程

[Previous Goal] 点击搜索按钮
[Previous Evaluation] 搜索框已输入关键词
[Memory] 已在 Google 首页，搜索词已输入

[Previous Action Results]
  OK

[Current Plan]
[x] 0: 打开搜索引擎
[>] 1: 输入搜索词并搜索
[ ] 2: 查看结果

[Current URL] https://www.google.com/search?q=python
[Page Title] python - Google Search

[Open Tabs]
  [abcd] python - Google Search (active)
  [ef12] Gmail

[Page DOM]
[0]<input value="python">
[1]<button>搜索
[2]<a href="...">Python 官方教程
...

[Downloads] New files available: report.pdf

[System Notice] WARNING: You have repeated the same action 5+ times.

[Planning Suggestion] You have been exploring for several steps without a structured plan.
```

### 4. 消息追加 (step.py L182)

```python
self.messages.append({"role": "user", "content": state_msg})
```

状态消息作为 user 角色追加到对话历史。

## 🎯 设计亮点

1. **信息段分离** — 每类信息有独立的 `[标签]` 前缀，LLM 可快速定位
2. **可选段设计** — 计划、下载、nudge 等都是可选的，不影响基本消息结构
3. **前序上下文传递** — 保留上一步的 goal/evaluation/memory，让 LLM 有连续感

## 📊 返回值结构

```
state_msg: str — 完整的 user 消息文本，包含所有信息段
```
