# Phase 4: 后处理 (_post_process)

> 源码位置: `src/tree_walker/agent/step.py` 第 560-611 行

## 📋 Phase 概述

`_post_process()` 在动作执行完成后更新 Agent 内部状态。包含：结果存储、计划更新、循环检测记录、失败计数管理和完成结果日志。

## 🔄 主要逻辑流程

```
_post_process(results, model_output) → None
  │
  ├── 1. 状态存储与计划更新                       (L574-579) → [详细文档](1-状态存储与计划更新.md)
  │     ├── state.last_result = results
  │     ├── state.last_model_output = model_output
  │     └── plan_manager.update_from_model_output(state, model_output) (可选)
  │
  └── 2.循环检测与失败计数管理                    (L582-610) → [详细文档](2-循环检测与失败计数管理.md)
        ├── loop_detector.record_action() (豁免过滤)
        ├── 失败计数: 单动作错误 → +1, early return
        ├── 成功 → 重置 consecutive_failures
        └── 完成 logging (颜色编码)
```

## 💡 总结

| 子步骤 | 源码行号 | 主要操作 | 输出 |
|--------|---------|---------|------|
| 状态存储与计划更新 | L574-579 | 保存结果 + 更新计划 | 更新 state |
| 循环检测与失败计数 | L582-610 | 记录动作 + 失败管理 | 更新 state |
