# 1-历史记录与事件发射

> 源码位置: `src/tree_walker/agent/step.py` 第 625-648 行

## 📋 方法作用

在 `_step()` 的 `finally` 块中保证执行。将当前步骤的完整快照追加到历史记录，并向可观测性系统发射步结束事件。

## 🔄 主要逻辑流程

```
_finalize() (L625-648)
  │
  ├── if model_output is not None:                  (L625)
  │     ├── 构建 state_summary                      (L627-632)
  │     │     └── {url, title, duration: time.time() - _step_start_time}
  │     └── history.history.append(AgentHistory(    (L633-638)
  │           step_number=n_steps,
  │           model_output=model_output,
  │           result=results,
  │           state_summary=state_summary,
  │         ))
  │
  └── if _obs_bus:                                  (L640-648)
        └── emit StepEndEvent(
              step=n_steps,
              duration_seconds=duration,
              is_done=any(r.is_done for r in results),
              consecutive_failures=state.consecutive_failures,
            )
```

## 🔍 详细步骤说明

### 1. 历史记录追加 (L625-638)

只在 `model_output` 非空时记录（异常步骤可能没有 model_output）：

```python
AgentHistory(
    step_number=self.state.n_steps,      # 当前步号
    model_output=model_output,           # LLM 完整输出
    result=results,                      # ActionResult 列表
    state_summary={                      # 页面快照
        "url": browser_state.url,
        "title": browser_state.title,
        "duration": time.time() - self._step_start_time,
    },
)
```

**用途**：
- `AgentHistoryList.final_result()` — 提取最终结果文本
- `AgentHistoryList.is_done()` — 判断任务是否完成
- `JudgeEvaluator.judge()` — 审查完整执行轨迹

### 2. StepEndEvent (L640-648)

```python
if self._obs_bus:
    duration = time.time() - self._step_start_time
    is_done = any(r.is_done for r in results) if results else False
    self._obs_bus.emit(StepEndEvent(
        step=self.state.n_steps,
        session_id=self._obs_session_id,
        duration_seconds=duration,
        is_done=is_done,
        consecutive_failures=self.state.consecutive_failures,
    ))
```

步结束事件被以下消费者处理：
- `MetricsAggregator` — 聚合统计
- `JsonlRecorder` — 写入 JSONL 日志
- `AnomalyDetector` — 异常检测
- `EventBridge` (TUI) — 事件面板显示

## 🎯 设计亮点

1. **finally 保证** — 无论成功/异常/超时，历史记录都会被保存
2. **条件记录** — model_output 为 None 时不记录（异常步骤），避免空数据
3. **n_steps 延迟递增** — 所有消费者使用当前步号后才 +1
