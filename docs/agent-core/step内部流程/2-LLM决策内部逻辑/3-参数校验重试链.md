# 3-参数校验重试链

> 源码位置: `src/tree_walker/agent/step.py` 第 410-477 行

## 📋 方法作用

对 LLM 返回的动作参数进行 Pydantic 模型校验。如果参数无效，将错误详情反馈给 LLM 并重试（最多 2 次）。

## 🔄 主要逻辑流程

```
_validate_params_or_retry(response, original_messages) → dict
  │
  ├── param_error = _validate_action_params(response)   (L416)
  │     ├── 查找 ACTION_DEFINITIONS[name]
  │     ├── _flatten_params_for_validation(params, name)
  │     ├── param_model.model_validate(flat_params)
  │     └── ValidationError → 提取错误字段: "field: error msg"
  │
  ├── param_error == None?
  │   └── Yes → return response                         (L417-418) ✅
  │
  └── for attempt in range(2):                          (L420-451) 🔄
        ├── 追加错误消息到 messages
        │     "Your action parameters are invalid: {param_error}. Please fix..."
        ├── LLM 重新调用
        │     llm.get_action(system_prompt, retry_messages, tool_schema)
        │
        ├── 空动作? → return _FALLBACK_DONE_OUTPUT      (L440-441)
        │
        ├── param_error = _validate_action_params(new_response)
        │   └── None? → return new_response              (L444-445) ✅
        │
        └── 继续重试...
             └── 仍无效 → return response (proceed anyway) (L447-451) ⚠️
```

## 🔍 详细步骤说明

### 1. 参数展平 (step.py L748-757)

LLM 可能返回嵌套的参数格式，需要展平：

```python
def _flatten_params_for_validation(params, action_name):
    if not params: return params
    # {"click": {"index": 5}} → {"index": 5}
    if action_name in params and isinstance(params[action_name], dict):
        return params[action_name]
    # 单个嵌套 dict 值
    dict_vals = {k: v for k, v in params.items() if isinstance(v, dict)}
    if len(dict_vals) == 1 and len(params) == 1:
        return list(dict_vals.values())[0]
    return params
```

### 2. Pydantic 校验 (step.py L453-477)

```python
@staticmethod
def _validate_action_params(response):
    action = response.get("action", {})
    name = action.get("name", "")
    params = action.get("params", {})

    definition = ACTION_DEFINITIONS.get(name)
    if definition is None: return None    # 无模型定义 → 不校验

    param_model = definition[0]           # Pydantic BaseModel 类
    flat_params = _flatten_params_for_validation(params, name)
    try:
        param_model.model_validate(flat_params)
        return None                       # 校验通过
    except ValidationError as e:
        parts = []
        for err in e.errors():
            field = ".".join(str(loc) for loc in err["loc"])
            parts.append(f"{field}: {err['msg']}")
        return "; ".join(parts)           # 返回错误描述
```

### 3. 重试策略

```
重试链：
  第一次调用 → 校验失败 → 重试 1 → 校验失败 → 重试 2 → 仍失败 → 使用原始输出
  │                              │                         │
  └── 最多 2 次重试              └── 每次追加错误详情     └── 不丢弃，继续执行
```

## 🎯 设计亮点

1. **参数展平兼容** — 兼容 LLM 多种输出格式（嵌套/扁平）
2. **错误反馈给 LLM** — 将 Pydantic 校验错误原文返回，LLM 能理解并修正
3. **非阻塞** — 重试失败后仍使用原始输出，不阻断流程
