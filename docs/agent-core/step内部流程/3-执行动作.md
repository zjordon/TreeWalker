# Phase 3: 执行动作 (_execute_actions)

> 源码位置: `src/tree_walker/agent/step.py` 第 490-556 行

## 📋 Phase 概述

`_execute_actions()` 是 Act 阶段的核心方法。解析 LLM 决策出的动作名称和参数，调用 `Tools.execute()` 执行，并通过超时保护和异常分类确保动作不会阻塞主循环。

## 🔄 主要逻辑流程

```
_execute_actions(model_output, browser_state) → [ActionResult]
  │
  ├── 1. 动作解析与事件发射               (L503-520) → [详细文档](1-动作解析与事件发射.md)
  │     ├── 检查 stopped/paused
  │     ├── 提取 action_name, action_params
  │     └── 发射 ToolCallEvent
  │
  └── 2. 动作执行与错误处理               (L522-556) → [详细文档](2-动作执行与错误处理.md)
        ├── asyncio.wait_for(tools.execute(), timeout=action_timeout)
        ├── TimeoutError → ActionResult(error=...)
        ├── 连接异常 → raise (向上传播触发重连)
        ├── 其他异常 → ActionResult(error=...)
        ├── 发射 ToolResultEvent
        └── URL 变化检测
```
