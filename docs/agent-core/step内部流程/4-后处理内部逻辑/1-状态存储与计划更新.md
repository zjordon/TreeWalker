# 1-状态存储与计划更新

> 源码位置: `src/tree_walker/agent/step.py` 第 574-579 行

## 📋 方法作用

将动作执行结果和 LLM 输出保存到 Agent 状态中，如果启用了计划系统，同步更新计划状态。

## 🔄 主要逻辑流程

```
_post_process() (L574-579)
  │
  ├── state.last_result = results                    (L574)
  ├── state.last_model_output = model_output          (L575)
  │
  └── if enable_planning and plan_manager:            (L578-579)
        └── plan_manager.update_from_model_output(state, model_output)
              ├── 路径 A: plan_update → 替换整个计划
              └── 路径 B: current_plan_item → 推进步骤索引
```

## 🔍 详细步骤说明

### 1. 状态存储 (L574-575)

```python
self.state.last_result = results               # list[ActionResult]
self.state.last_model_output = model_output    # dict {evaluation, memory, goal, action}
```

保存到 `AgentState`，供下一步的 `_prepare_context()` 读取：
- `last_result` → `build_state_message()` 的 `[Previous Action Results]` 段
- `last_model_output` → `build_state_message()` 的 `[Previous Goal/Evaluation/Memory]` 段

### 2. 计划更新 (L578-579)

`PlanManager.update_from_model_output()` 两条互斥路径：

**路径 A — 完全替换计划**：
```python
# LLM 输出包含 plan_update 字段
if 'plan_update' in model_output:
    state.plan = [PlanItem(text=text) for text in steps]
    state.current_plan_item_index = 0
    state.plan[0].status = 'current'  # 第一步标记为当前
```

**路径 B — 推进步骤索引**：
```python
# LLM 输出包含 current_plan_item 字段
if 'current_plan_item' in model_output:
    new_idx = model_output['current_plan_item']
    # 中间步骤标记为 done
    for i in range(old_idx, new_idx):
        state.plan[i].status = 'done'
    # 新步骤标记为 current
    state.plan[new_idx].status = 'current'
    state.current_plan_item_index = new_idx
```

## 🎯 设计亮点

1. **互斥路径** — plan_update 和 current_plan_item 不会同时生效
2. **状态即时更新** — last_result/last_model_output 在下一步准备上下文时即可使用
