# 2-循环检测与失败计数管理

> 源码位置: `src/tree_walker/agent/step.py` 第 582-610 行

## 📋 方法作用

记录当前动作到循环检测器，管理失败计数器（递增或重置），并在任务完成时输出颜色编码日志。

## 🔄 主要逻辑流程

```
_post_process() (L582-610)
  │
  ├── 1. 循环检测记录                              (L582-586)
  │     ├── 提取 action_name, action_params
  │     ├── if action_name not in _LOOP_EXEMPT_ACTIONS:
  │     │     └── loop_detector.record_action(name, params)
  │     └── 豁免: wait, done, go_back
  │
  ├── 2. 失败计数管理                              (L589-596)
  │     ├── if 单动作错误:
  │     │     ├── consecutive_failures += 1
  │     │     └── return (early)
  │     └── if consecutive_failures > 0:
  │           └── consecutive_failures = 0  (成功重置)
  │
  └── 3. 完成结果日志                              (L599-610)
        ├── if result.is_done and result.success:
        │     └── logger.info("\033[32m Task SUCCESS\033[0m")
        └── if result.is_done and not result.success:

```

## 🔍 详细步骤说明

### 1. 循环检测记录 (L582-586)

```python
action = model_output.get("action", {})
action_name = action.get("name", "done")
action_params = action.get("params", {})

if action_name not in _LOOP_EXEMPT_ACTIONS:
    self.loop_detector.record_action(action_name, action_params)
```

**豁免动作**：`wait`、`done`、`go_back` 不参与循环检测，因为它们必然重复或为终态。

**哈希规则**（loop_detector.py L21-23）：
```python
key_params = {k: v for k, v in params.items() if k not in ("text", "clear")}
action_hash = f"{name}:{json.dumps(key_params, sort_keys=True, default=str)}"
```

过滤 `text` 和 `clear` 参数，因为输入内容必然不同，不应影响循环检测。

### 2. 失败计数管理 (L589-596)

```
失败计数决策树:
├── 单动作错误 (len(results)==1 and results[-1].error)
│   ├── consecutive_failures += 1
│   └── return (early) — 不执行后续逻辑
└── 无错误 (或多个结果中有成功的)
    └── if consecutive_failures > 0:
          └── consecutive_failures = 0  — 成功后重置
```

**关键设计** — 只要有一个步骤成功，就重置连续失败计数。这意味着只有**连续**的失败才会触发终止。

### 3. 完成结果日志 (L599-610)

```python
if results and results[-1].is_done:
    result = results[-1]
    if result.success:
        logger.info("\n\033[32m Task SUCCESS\033[0m\n%s\n", result.extracted_content or "")
    else:
        logger.info("\n\033[31m Task FAILED\033[0m\n%s\n", result.extracted_content or "")
```

绿色 SUCCESS / 红色 FAILED，配合 extracted_content 显示最终结果摘要。

## 🎯 设计亮点

1. **豁免过滤** — 终态动作和等待动作不参与循环检测
2. **参数过滤** — 排除 text/clear，只比较"做什么"而非"输入什么"
3. **连续失败语义** — 一次成功即重置，只有连续失败才触发终止
