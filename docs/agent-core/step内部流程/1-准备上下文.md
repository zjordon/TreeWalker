# Phase 1: 准备上下文 (_prepare_context)

> 源码位置: `src/tree_walker/agent/step.py` 第 124-193 行

## 📋 Phase 概述

`_prepare_context()` 是 Sense 阶段的核心方法，负责从浏览器获取当前页面状态，结合前序步骤的上下文、循环检测结果、计划状态等，构建发送给 LLM 的状态消息。这是五阶段管线中信息量最密集的阶段。
