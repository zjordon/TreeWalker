# issue #194: [runner] API 限流重试消耗步数预算，整任务被烧死

**现象**（B 轮 550）：Step 16 起连续 "Rate limit reached. Waiting before retry"
（anthropic SDK 重试），16/17/18/19 步全部计步但零进展，任务以空答案耗尽。
该任务前 10 步为四次尝试中最佳路径（计划完整），**死于基建而非能力**。

**修复方向**：限流/网络类等待不计入 `max_steps` 与任务超时（或单列
"infra wait" 预算）；与 #180（挂滞）同属"评测基建不应吃任务预算"。
**验收**：注入限流场景回放，有效步数消耗与无限流时一致。
证据：分析文档 550 条目（B 轮轨迹 `results/self_overestimate/B_20260915/task_550.log`）。
