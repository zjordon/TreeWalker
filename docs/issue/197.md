## 现象（V 轮 2026-09-18 全量，vision=true，实锤）

10 个任务以 2-3 步死亡，final_result 均为 "No action returned by LLM"：
**V 新败 7**（108/109/200/492/495/696/782）+ C 也败交叉 3（544/545/549——
本轮不是死于 C 轮老原因，先死于此）。对照：同任务 C 轮（文本口径）108=1.0。

## 机制（轨迹原文，task 108 现场）

```
multi_act: LLM emitted list with 1 action(s): ['?']      ← 模型吐字面 "?" 当动作
LLM returned empty action, retrying with clarification...
multi_act: LLM emitted list with 1 action(s): ['?']       ← 重试原样再吐 "?"
LLM still returned empty action after retry, using fallback done → 任务判死（2 步）
```

## 量化（V 轮四段日志全量）

- `?` 伪动作共 **50 次**；进入澄清重试 47 次；**二连判死 9-10 次**
  ——单次重试救回率 81%，但死刑一判就是整任务。
- 时间分布横跨全程（09-17 11:04 → 09-19 00:48）——**持续性间歇退化，
  非瞬时故障**。
- 文本口径（B/C 轮）仅零星出现且可恢复（C 轮 task 2 单次后即恢复）——
  视觉模式特有。
- **影响 ≈ 10/184 ≈ 5.4pp SR**——V 轮（72.3%）最大单项可修复损失。

## 修复方向

1. `?`（及同类单字符伪动作）识别为无效响应：现有"澄清重试"没有改变
   模型行为（原样再吐）——重试需**换采样参数（温度/种子）**或**该步
   降级走非视觉通道**；
2. 死刑门槛放宽：两次即 fallback-done 过脆——预算 30 步才用 2 步，
   应在预算内持续重试/降级，判死至少要求 N≥4 次连续无效；
3. 评测口径：此类死亡按事故处理（定向重试入账，同 #180 启动挂滞惯例）。

## 验收

注入 '?' 响应回放：换参/降级重试后任务继续；连续 2 次 '?' 不再判死。
