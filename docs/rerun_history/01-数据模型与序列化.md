# 01 · 数据模型与序列化

> 目标：定义「历史」的内存模型与磁盘格式，并实现 save/load。本节是后续录制、匹配、重放的基石。

## 1. 现状

`src/tree_walker/agent/views.py:79` 现有的 `AgentHistory` 很轻：

```python
class AgentHistory(BaseModel):
    step_number: int
    model_output: dict[str, Any]          # LLM 决策输出（含 actions/action、next_goal 等）
    result: list[ActionResult]
    state_summary: dict[str, Any] | None = None   # 仅 url/title/duration，done 步多一个 dom_excerpt

    class Config:
        arbitrary_types_allowed = True


class AgentHistoryList(BaseModel):
    history: list[AgentHistory] = Field(default_factory=list)

    def final_result(self) -> str | None: ...
    def is_done(self) -> bool: ...
    def is_successful(self) -> bool: ...
```

它**没有**重放所需的两个关键信息：
1. 每个动作「当年点的哪个元素」（用于跨会话重定位）。
2. 步骤计时（用于重放步间延迟）。

## 2. 扩展设计

### 2.1 `AgentHistory` 新增字段

```python
class StepMetadata(BaseModel):
    """单步计时。"""
    step_start_time: float
    step_end_time: float
    step_number: int
    step_interval: float | None = None     # ⚠️ 存的是【上一步】的耗时，见 04 §步间延迟

    @property
    def duration_seconds(self) -> float:
        return self.step_end_time - self_start_time


class AgentHistory(BaseModel):
    step_number: int
    model_output: dict[str, Any]
    result: list[ActionResult]
    state_summary: dict[str, Any] | None = None
    # ── 新增（重放所需）─────────────────────────────────────
    interacted_element: list[dict[str, Any] | None] | None = None
    #   与 model_output 的 actions 列表【等长、按位对应】；
    #   每项是 DOMInteractedElement.to_dict() 的产物，无 index 的动作为 None。
    metadata: StepMetadata | None = None
    # ── 不含 screenshot_path（本方案决定无截图）──────────────

    class Config:
        arbitrary_types_allowed = True
```

**为什么 `interacted_element` 存 dict 而非对象**：要落盘成 JSON。投影时用现成的 `DOMInteractedElement.to_dict()`（`browser/views.py:727`）。

**为什么不要 `screenshot_path`**：本方案决策「完全不要截图」（见 06）。历史文件更轻、无磁盘 I/O、无敏感画面泄露风险；代价是 AI 摘要失去视觉依据——已在 06 用「文本+统计」判定补齐。

## 3. 序列化（save）

新增 `AgentHistoryList.save_to_file()`，对齐 browser-use `views.py:627`：

```python
def save_to_file(self, filepath: str | Path, sensitive_data: dict[str, str] | None = None,
                 action_registry_version: str | None = None) -> None:
    Path(filepath).parent.mkdir(parents=True, exist_ok=True)
    data = self.model_dump(sensitive_data=sensitive_data)
    # 顶层写注册表版本号，防反序列化时 action 注册表漂移（见 §5）
    data["action_registry_version"] = action_registry_version or _default_registry_version()
    with open(filepath, "w", encoding="utf-8") as f:
        json.dump(data, f, indent=2, ensure_ascii=False)
```

### 3.1 自定义 `model_dump` 的三件事

`AgentHistory.model_dump(sensitive_data=...)`（仿 browser-use `views.py:550`）：

1. **`model_output`（dict）原样序列化**：TreeWalker 的 action 是纯 dict，不需要 browser-use 的 `mode='json'` enum 处理。
2. **敏感数据脱敏**：只对「input 类」动作参数过滤（见 §4），`result` **不过滤**。
3. **`interacted_element` 用 `DOMInteractedElement.to_dict()` 的产物**：存盘时已是 dict，直接写入。

## 4. 敏感数据脱敏

移植 browser-use `utils.py:51` 的 `redact_sensitive_string`：

```python
def redact_sensitive_string(value: str, sensitive_values: dict[str, str]) -> str:
    # 按值长度【从长到短】排序，防止短值先匹配造成泄露
    for key, secret in sorted(sensitive_values.items(), key=lambda kv: len(kv[1]), reverse=True):
        value = value.replace(secret, f"<secret>{key}</secret>")
    return value
```

**过滤范围（重要边界）**：
- ✅ 只过滤「input 类」动作的参数值（典型 `input_text.text`，以及 `search`/`extract` 的 `query`）。
- ❌ **不过滤** `result`（`extracted_content`/`long_term_memory`/`error` 即使含密码也原样保存）——沿用 browser-use 的有意权衡：`result` 含 agent 推理所需信息，过滤会损害可读性。
- ⚠️ 风险提示：若历史文件会**外发**，需重新评估——`result` 里可能含页面提取出的敏感数据（订单详情等）。生产化阶段可加 `redact_results` 开关。

按长度降序是为了避免 `password123` 被 `password` 先匹配掉前缀导致泄露。

## 5. action 注册表版本号

**问题**：存盘时 action 是 JSON。读盘时 TreeWalker 虽不用 `output_model` 重建动作（dict 直接可用），但若**动作集合本身变了**（新增/删除/改参数），旧历史里出现的 action 名可能在新版注册表中不存在，重放会失败。

**方案**：存盘时写顶层 `action_registry_version`：

```python
def _default_registry_version() -> str:
    # 内置动作名集合的稳定指纹；自定义动作注册后应重新计算
    names = tuple(sorted(tools.registry.actions.keys()))
    return "v1-" + hashlib.sha256("|".join(names).encode()).hexdigest()[:12]
```

`load_from_file` 校验：若版本不一致，记 warning（不强制 fail，允许向前兼容），并在重放遇到未知动作时给出可读错误。

## 6. 反序列化（load）

```python
@classmethod
def load_from_file(cls, filepath: str | Path) -> "AgentHistoryList":
    with open(filepath, encoding="utf-8") as f:
        data = json.load(f)
    return cls.load_from_dict(data)

@classmethod
def load_from_dict(cls, data: dict) -> "AgentHistoryList":
    # 校验注册表版本（宽松：不一致只 warning）
    _check_registry_version(data.get("action_registry_version"))
    # 老格式兼容：缺 interacted_element 补 None
    for h in data.get("history", []):
        if "interacted_element" not in (h or {}):
            h["interacted_element"] = None
    return cls.model_validate(data)
```

### 6.1 关键简化：无需 `output_model`

browser-use 的 `load_from_dict` **必须**传入动态生成的 `output_model`，才能把 action dict 还原成 `ActionModel` 实例（`views.py:675`）。**TreeWalker 不需要**——这里的 action 一直是纯 dict，重放时直接 `action["name"]` / `action["params"]` 取用。这是本方案相对 browser-use 的一项显著简化（见 README 差异表）。
