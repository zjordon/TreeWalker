# 05 · 变量检测与替换

> 目标：自动发现历史里「可替换的值」（邮箱/姓名/日期/电话…），让用户用新数据重放（如换邮箱重填表单）。这是「一次录制，多次重放」的关键。

## 1. 数据模型

```python
class DetectedVariable(BaseModel):
    name: str                    # 变量名（如 'email'）
    original_value: str          # 历史中的原始值（用于精确替换）
    type: str = "string"
    format: str | None = None    # 格式提示：email/phone/date/number/url/postal_code
```

## 2. 检测器（纯规则，不调 LLM）

新建 `src/tree_walker/agent/variable_detector.py`，移植 browser-use `variable_detector.py`（~277 行，全文纯规则）。

### 2.1 入口

```python
def detect_variables_in_history(history: AgentHistoryList) -> dict[str, DetectedVariable]:
    detected: dict[str, DetectedVariable] = {}
    seen_values: set[str] = set()    # 同一原始值只检测一次
    for item in history.history:
        actions = item.model_output.get("actions") or [item.model_output.get("action", {})]
        interacted = item.interacted_element or []
        for i, action in enumerate(actions):
            elem = interacted[i] if i < len(interacted) else None
            _detect_in_action(action.get("params", {}), elem, detected, seen_values)
    return detected
```

### 2.2 检测范围（重要限制）

只检查动作参数里的**两个字段**：

```python
FIELDS_TO_CHECK = ["text", "query"]
```

即只对 `input_text` 的 `text`、`search`/`extract` 的 `query` 生效。其他动作（click/scroll/done）不检测。

### 2.3 两条策略（按优先级）

```
策略 1（首选）: _detect_from_attributes(element.attributes)   ← 基于元素 HTML 属性
   ↓ 失败
策略 2（兜底）: _detect_from_value_pattern(value)             ← 基于值本身的正则
```

**策略 1：基于元素属性（最可靠）**

先看 HTML5 `type`（最具体）：

| `type` | 返回 `(name, format)` |
|--------|----------------------|
| `email` | `('email', 'email')` |
| `tel` | `('phone', 'phone')` |
| `date` | `('date', 'date')` |
| `number` | `('number', 'number')` |
| `url` | `('url', 'url')` |

再看语义属性关键词：把 `id`/`name`/`placeholder`/`aria-label` 拼成 `combined_text`，按下表顺序匹配（顺序重要）：

| 关键词（优先级降序） | 变量名 | format |
|---------------------|--------|--------|
| address/street/addr（区分 billing/shipping） | `billing_address`/`shipping_address`/`address` | — |
| comment/note/message/description | `comment` | — |
| email/e-mail | `email` | `email` |
| phone/tel/mobile/cell | `phone` | `phone` |
| first+name / last+name / full+name / 仅 name | `first_name`/`last_name`/`full_name`/`name` | — |
| date/dob/birth | `date` | `date` |
| city / state\|province / country / zip\|postal\|postcode | `city`/`state`/`country`/`zip_code` | `postal_code`（仅 zip） |
| company\|organization | `company` | — |

**策略 2：基于值模式正则（兜底）**

| 模式 | 正则（示意） | 变量名 |
|------|------|--------|
| 邮箱 | `^[\w\.-]+@[\w\.-]+\.\w+$` | `email` |
| 电话 | 去分隔符后 ≥10 位纯数字 | `phone` |
| 日期 | `^\d{4}-\d{2}-\d{2}$` | `date` |
| 姓名 | 首字母大写、2–30 字符；1 词→`first_name`，2 词→`full_name`，更多→`name` | `first_name`/`full_name`/`name` |
| 纯数字 1–9 位 | `^\d{1,9}$` | `number` |

### 2.4 去重命名 `_ensure_unique_name`

若 `first_name` 已存在，生成 `first_name_2`、`first_name_3`…（整数后缀从 2 起）。

## 3. 变量替换 `_substitute_variables_in_history`

### 3.1 替换链路：变量名 → 原始值 → 新值

```python
def _substitute_variables_in_history(self, history, variables: dict[str, str]) -> AgentHistoryList:
    detected = detect_variables_in_history(history)
    # 把「变量名→新值」翻译成「旧值→新值」
    value_replacements: dict[str, str] = {}
    for var_name, new_value in variables.items():
        if var_name in detected:
            value_replacements[detected[var_name].original_value] = new_value
        else:
            logger.warning("Variable %r not found in history, skipping", var_name)

    modified = copy.deepcopy(history)    # 不污染原始历史
    for item in modified.history:
        actions = item.model_output.get("actions") or [item.model_output.get("action", {})]
        for action in actions:
            params = action.get("params", {})
            _substitute_in_dict(params, value_replacements)
    return modified
```

### 3.2 递归替换 `_substitute_in_dict`

```python
def _substitute_in_dict(data: dict, replacements: dict[str, str]) -> int:
    count = 0
    for key, value in data.items():
        if isinstance(value, str):
            if value in replacements:        # ⚠️ 仅【精确整串匹配】
                data[key] = replacements[value]
                count += 1
        elif isinstance(value, dict):
            count += _substitute_in_dict(value, replacements)
        elif isinstance(value, list):
            for i, item in enumerate(value):
                if isinstance(item, str) and item in replacements:
                    value[i] = replacements[item]
                    count += 1
    return count
```

⚠️ **只做精确整串匹配，不做子串替换**。原始值是 `"John"`，不会替换 `"John Doe"` 里的 `"John"`。这避免误替换，但也要求检测时拿到完整值（这就是检测器只看 `text`/`query`——用户填入的完整值）。

### 3.3 替换范围（重要边界）

✅ **只作用在 `model_output` 的动作参数**（典型 `input_text.text`、`search`/`extract` 的 `query`）。

❌ **不触碰**：
- `interacted_element`（`element_hash`/`stable_hash`/`x_path`/`ax_name`）——**完全不遍历、不修改**；
- `result`（`ActionResult.extracted_content` 等）——不在替换范围。

**为什么不动 `interacted_element`**：`element_hash` 是目标元素的标识，与「填入的值」无关。换了邮箱地址，邮箱输入框还是那个输入框（hash 不变）。**变量替换与元素重定位是两个正交的层面**——替换改「值」，匹配改「index」。

### 3.4 写回 action（TreeWalker 简化）

browser-use 费力处理 Pydantic 模型不可变性（`service.py:4112`：`object.__setattr__` 绕过冻结）。**TreeWalker 不需要**——action 是纯 dict，`_substitute_in_dict` 直接原地改 dict 即可。这是 dict-action 带来的又一项简化。
