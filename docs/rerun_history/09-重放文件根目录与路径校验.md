# 09 · 重放文件根目录配置 + 相对路径强制校验

> 本文是**设计文档**（尚未落地编码）。描述如何给历史重放的 save/load 加一个可配置的「根目录」+ 强制相对路径校验。

## 1. 背景与目标

当前 `save_history` / `load_and_rerun` 接受任意路径（相对或绝对），重放文件散落在 CWD 各处，不便管理，也存在越权写入风险。本次要：

1. **新增配置项**指定重放文件的**根目录**；未配置时默认 `<项目根>/rerun-history`（项目根 = CWD）。
2. **保存**路径必须相对（绝对路径拒绝）。
3. **加载**路径必须相对（绝对路径拒绝）。
4. **拒绝 `..` 越界**——相对路径解析后必须落在根目录之内（防止 `../` 写到根目录外）。

> 命名说明：默认目录名采用 `rerun-history`（与功能名「历史重放」、分支 `feat/98-rerun-history`、`docs/rerun_history` 一致；最初讨论时出现的 `return-history` 视作笔误）。

## 3. 设计

### 3.1 配置项（`src/tree_walker/config.py`）

`AgentSettings` 加字段：

```python
@dataclass
class AgentSettings:
    ...
    # 重放文件根目录；相对路径=相对 CWD(项目根)；可用绝对路径覆盖。
    # save_history / load_and_rerun 的相对路径都相对此根解析。
    rerun_history_dir: str = "rerun-history"
```

`load_settings()` 读环境变量：

```python
agent = AgentSettings(
    ...,
    rerun_history_dir=os.environ.get("AGENT_RERUN_HISTORY_DIR", "rerun-history"),
)
```

> 根目录本身允许相对或绝对（它是受信配置，非调用方输入）；默认相对 `"rerun-history"`，自然落在 CWD（=项目根）下。

### 3.2 Agent 存字段（`src/tree_walker/agent/agent.py`）

构造函数存一下（与其它 `self.x = _settings.x` 并列）：

```python
self.rerun_history_dir = _settings.rerun_history_dir
```

### 3.3 路径校验 + 根目录解析（`src/tree_walker/agent/rerun.py`）

新增**模块级公共函数**（供 Agent 方法 / 示例 / CLI 复用）：

```python
from pathlib import Path

def resolve_rerun_path(rerun_history_dir: str, file_path: str | Path) -> Path:
    """相对路径 → 相对根目录的路径。

    - 绝对路径 → ValueError（保存/加载路径必须相对）。
    - 含 ``..`` 越界（解析后跳出根目录）→ ValueError。
    - 合法相对路径 → ``root / file_path``。
    """
    p = Path(file_path)
    if p.is_absolute():
        raise ValueError(
            f"重放文件路径必须是相对路径（相对 rerun_history_dir={rerun_history_dir!r}），"
            f"收到: {file_path}"
        )
    root = Path(rerun_history_dir)
    resolved = root / p
    try:  # 拒绝 `..` 越界：解析后必须仍在 root 之内
        resolved.resolve().relative_to(root.resolve())
    except ValueError:
        raise ValueError(
            f"重放文件路径越界（跳出根目录 {str(root)!r}）: {file_path}"
        )
    return resolved
```

Agent 上加便捷方法：

```python
def rerun_path(self, file_path: str | Path) -> Path:
    """把相对路径解析到 self.rerun_history_dir 之下（含校验）。"""
    return resolve_rerun_path(self.rerun_history_dir, file_path)
```

接入两个公共 API（底层 `save_to_file`/`load_from_file` **不改**，只接收已解析路径）：

```python
def save_history(self, file_path: str | Path | None = None) -> None:
    if not file_path:
        file_path = "AgentHistory.json"
    sensitive = {p: r for r, p in self._sensitive_map.items()} if self._sensitive_map else None
    self.history.save_to_file(
        self.rerun_path(file_path),                       # ← 经校验+解析
        sensitive_data=sensitive,
        action_registry_version=self.tools.registry.registry_version,
    )

async def load_and_rerun(self, history_file, variables=None, **kwargs):
    history = AgentHistoryList.load_from_file(self.rerun_path(history_file))  # ← 经校验+解析
    ...
```

### 3.4 示例对齐（`examples/features/douyin_upload_rerun.py`）

`build_rerun_history` 改用 `resolve_rerun_path` 解析 src/dst（根取自 `load_settings().agent.rerun_history_dir`），保证「库保存的文件」与「示例读写的文件」落同一根目录：

```python
from tree_walker.agent.rerun import resolve_rerun_path
from tree_walker.config import load_settings

def build_rerun_history(src_history, dst_history, replacements):
    root = load_settings().agent.rerun_history_dir
    src = resolve_rerun_path(root, src_history)
    dst = resolve_rerun_path(root, dst_history)
    with open(src, encoding="utf-8") as f:
        data = json.load(f)
    count = replace_values_in_history_dict(data, replacements)
    with open(dst, "w", encoding="utf-8") as f:
        json.dump(data, f, indent=2, ensure_ascii=False)
    return count
```

`HISTORY_FILE` / `RERUN_HISTORY_FILE` 保持相对字面量（如 `Path("douyin_upload_history.json")`），由 `resolve_rerun_path` 解析。

`examples/features/rerun_history.py` **无需改调用**——`save_history("agent_history.json")` / `load_and_rerun(...)` 库内自动解析。

### 3.5 CLI（`src/tree_walker/cli.py`）

`--rerun` 去掉 `exists=True`（文件在根目录、不在 CWD，CWD 下查存在性会误报）；`_rerun()` 把相对路径原样交给 `agent.load_and_rerun(...)`，由库解析+校验：

```python
@click.option(
    "--rerun", "rerun_path", default=None, type=click.Path(dir_okay=False),
    help="重放指定历史文件（相对 rerun_history_dir；不进入交互 TUI）",
)
```

## 4. 行为示例

| 场景 | 结果 |
|------|------|
| 无配置 | 根目录 `./rerun-history/`（相对 CWD） |

## 6. 测试 / 验证

- **单测**：
  - `resolve_rerun_path` 各分支：相对 OK（`root / rel`）；绝对路径 `ValueError`；`..` 越界 `ValueError`；子目录相对路径 OK。
  - `save_history("a/b.json")` 写到 `<tmp cwd>/rerun-history/a/b.json`（用 tmp 目录 + 校验落点）。
  - `save_history("/abs")` / `load_and_rerun("/abs")` 抛 `ValueError`。
  - env `AGENT_RERUN_HISTORY_DIR` 覆盖默认值（`load_settings()` 单测）。
- `uv run python -m pytest tests/ -q` 全绿。
- **手工**：抖音示例设 `AGENT_RERUN_HISTORY_DIR`，确认文件落指定根目录；传绝对路径确认报错。

## 7. 备注 / 边界

- **校验只在公共 API**（`save_history` / `load_and_rerun`）；底层 `AgentHistoryList.save_to_file` / `load_from_file` 保持原样（接收已解析路径，职责单一，也方便外部已解析路径直传）。
- **根目录可绝对可相对**（受信配置）；只有**调用方传入的 save/load 路径**强制相对 + 禁越界。
- 「项目根」按 CWD 解释（运行命令的目录）；默认相对 `"rerun-history"` 即落在 CWD 下，无需额外探测项目根。
