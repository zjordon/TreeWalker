P5 原生 <select> 测试夹具

每个 fieldset = 一个 case，对应 docs/p5/01-select-as-variable-plan.md 的一条验证点。HTML 注释里写了预期录制 / 检测 / 重放行为。

怎么用：用 TreeWalker 录制这个页面，依次操作每个下拉框（选非默认项），停止后检查落盘 history.json。
标签含义：应自动检测 = select 带 _detect_from_attributes 认的英文关键词； 需手动标注 = 无关键词，走 P4 手动标注（strFields 含 value/label）； 不应检测（反例） = 验证保守检测不误报。
关键词清单见 src/tree_walker/agent/variable_detector.py:62-112：email/phone/name/date/address/city/state/province/country/zip/...（仅英文，中文 aria-label 不命中）。
Case 1 · 国家 应自动检测 → country

选中「中国」→ 录得 value="cn" + label="中国"；检测出变量 country="中国"。这是覆盖整条 value/label/检测/CSV/回归链路的主用例。

Case 2 · 省份 应自动检测 → state（注意归一）

选中「广东省」→ 检测出变量 state="广东省"（province 被 _detect_from_attributes 归一为 state）。

Case 3 · 城市 不应检测（反例）/ 可手动标注

选中「北京」→ 录得 value/label，但 不自动检测（中文 aria-label 无英文关键词）；编辑器手动标注默认落到 label。

Case 4 · 每页条数 需手动标注 / value==label 兜底

选中「50」→ value="50"、label="50"；测 value 兜底路径（label==value 时二者等价）。

Case 5 · 颜色 option 无 value 属性的边界

option 没有 value 属性时，select.value 隐式取文本；验证录制器不丢值、label 与 value 都拿到「绿」。

Case 6 · 账单州 / 收货州 变量名去重 → state + state_2

两个 id 都含 "state" → 都归一为变量名 state；_ensure_unique_name 把第二个改成 state_2。

Case 7 · 文本输入 与 select 变量混合，互不干扰

既有文本变量（email/full_name/address）又有 select 变量，验证两套检测互不干扰、命名各自唯一。

附：两个无法用本页 DOM 测的点
  • 旧历史兼容（value 兜底）：加载只有 value、无 label 的旧 select history，重放仍按 value 选。需手工编辑一份去掉 label 的 history.json 测，DOM 造不出来。
  • 空 label 省略：录制端空 label 时省略 label key（label ? {label} : {}），检测分支应跳过不误报。
