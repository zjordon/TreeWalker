# Quirks — douyin.com

1. **文件上传必须使用直接注入**: 页面所有的 `<input type=file>`（无论视频还是图片封面）必须通过 `upload_file(index, path)` 直接注入路径。绝不能先点击上传按钮或 input，否则会触发无法控制的 OS 文件选择对话框。

2. **SPA 流程与 DOM 延迟加载**: 上传视频后，URL 会从 `/content/upload` 跳转到 `/content/post/video`。但跳转后编辑表单（标题、描述输入框）不会立即出现，页面先显示文件解析进度（百分比）。必须使用 `wait(seconds)` 等待解析完成，直到在 DOM 中观察到 `基础信息` 区块出现后，才能执行 `input_text` 填写标题和描述。

3. **自主声明模态框的状态依赖**: 在处理“自主声明”弹窗时，底部的 `确定` 按钮默认是 `disabled=true` 的。你**必须先点击**具体的声明选项（如 `内容由AI生成` 或 `无需添加自主声明` 的 label 元素），才会解除按钮的禁用状态。不要试图强行点击禁用状态的确定按钮。

4. **页面包含多个同名/同类的 file input**: 编辑页面存在多个 `<input type=file name=upload-btn>`，均用于图片（`accept=image/...`），分布在封面设置、扩展信息等区域。封面编辑模态框内甚至存在成对的 input（初始上传与替换）。操作时需通过上下文（如是否在 `设置封面` 模态框内）或精确的 index 来区分，避免将封面图传到错误的组件中。
