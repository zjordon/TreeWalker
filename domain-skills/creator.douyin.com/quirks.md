# Quirks — douyin.com

1. **隐藏文件输入框要求**：视频和图片上传控件均为隐藏的 `<input type="file">`（隐藏在按钮或交互区域之下）。绝对不能尝试点击这些 input 或其父级按钮来触发上传，这会打开操作系统的文件选择对话框导致自动化卡死。**必须**使用直接文件路径注入（如 Playwright 的 `set_input_files` 或等效的 upload_file 动作）。
2. **全流程为 SPA 单页应用**：从首页到上传、信息编辑，全程 URL 通常不会发生大的改变（维持 `.../content/post/video?enter_from=publish_page`）。无法通过 URL 来判断当前处于哪个阶段，必须依赖 DOM 内容（如寻找 "基础信息" 表单，或寻找上传进度条）来判断状态。
3. **严格的上传后等待依赖**：在注入视频文件后，页面会显示 "文件解析中，请稍等..."。在解析完成并完全渲染出信息编辑表单（标题/描述框等）之前，后续的表单元素可能存在于 DOM 中但处于不可交互状态。需要显式等待上传进度条消失。
4. **多个相似文件上传 input 的歧义性**：页面中至少存在三个文件上传 input，且均无 ID。区分方法：
    - 视频文件：`accept` 属性包含 `video/*` 等。
    - 封面图片（主页面）：`accept` 属性包含 `image/png,image/jpeg,image/jpg`，且带有 `name=upload-btn`。
    - 封面图片（编辑弹窗内）：`accept` 属性包含 `image/bmp,image/webp,image/tif`。
5. **封面编辑器的覆盖层渲染**：点击 "选择封面" 并不会跳转新页面，而是动态加载一个包含 `canvas` 的全屏/局部覆盖层（编辑器）。封面上传成功后，必须点击覆盖层内的 `完成` 按钮以关闭该状态并返回主编辑表单。
