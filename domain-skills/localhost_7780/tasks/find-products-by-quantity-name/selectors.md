# Selectors — localhost

| 元素用途 | 怎么找到它 | 稳定标识 | 备注 |
|---|---|---|---|
| 数量范围起点 | Filters 面板 Quantity 行 from 输入框 | `name=qty[from]`, `type=text` | id 是随机的（如 PHS74DC），不要依赖 id |
| 数量范围终点 | Filters 面板 Quantity 行 to 输入框 | `name=qty[to]`, `type=text` | id 是随机的（如 SQ57YUG） |
| 应用筛选 | 筛选面板底部 | 可见文本"Apply Filters" | 旁边是 Cancel |
